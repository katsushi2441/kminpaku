# Kurage 民泊できる場所チェック（kminpaku）

住所を入れると、その場所の**用途地域**（建蔽率・容積率つき）と、その自治体の
**民泊の上乗せ条例**（区域・期間の制限）を返します。

民泊には制度が3つあります。住宅宿泊事業法（届出・年180日）、国家戦略特別区域法の
特区民泊（認定）、旅館業法の簡易宿所（許可）。窓口も条件も別々で、住所から横断して
引ける場所がありません。このシステムは、調べる前の下ごしらえをします。

公開版（無料・登録不要）: https://kurage.exbridge.jp/kminpaku.php/

## この製品がしないこと

- **営業できる・できないを断定しません。**
- **条例を要約・解釈しません。** 出すのは条例に書いてある文のままです。
- **収録していない自治体を「区域外」と書きません。**「未収録」と書いて区別します。
- **外部のAIやAPIに住所を送りません。** 住所の位置を引く国土地理院の検索だけ使います。

最後の判断は必ず自治体の窓口（保健所・都市計画課）で確かめてください。

## 画面

| URL | 内容 |
|---|---|
| `/` | 住所で調べる |
| `/check?q=住所` | 判定（用途地域・上乗せ条例・3制度の違い） |
| `/jorei` `/jorei/{自治体}` | 上乗せ条例のある自治体と、その区域・期間の制限 |
| `/data` | 収録している市区町村と時点 |
| `/about` | 何をして、何をしないか |

## このリポジトリについて

コード（`php/kminpaku.php`・`scripts/`）と出典の資料（`data/`）を置いています。全国の用途地域を詰めた SQLite（約57MB）は含みません。
`scripts/fetch_youto.py` と `scripts/build_db.py` で作れます。作り終えた一式と手順書は Kurage App Store で配布しています。
https://kappstore.exbridge.jp/app.php?id=c36227d2b62b8517

## 置き方

1. `kminpaku.php` と `kminpaku_data/` を置く
2. その階層の `.htaccess` に `AddHandler php-script .php` を書く（heteml の既定は PHP 5.6）
3. ブラウザで開く

PHP 8 と PDO SQLite だけで動きます。データベースサーバーも常駐プロセスもポートも要りません。

**用途地域は都道府県ごとに1ファイルです**（`kminpaku_data/youto_<都道府県>.sqlite`）。
要る都道府県のファイルだけ置けば動きます。置いていない県は「未収録」と返します。

## データを新しくする

```bash
python3 scripts/fetch_youto.py --all          # 用途地域（都道府県ごと・全国で約1.4GB）
python3 scripts/fetch_jorei.py                # 上乗せ条例の一覧と、国のとりまとめPDF
python3 scripts/parse_jorei_pdf.py            # 条例の区域・期間を取り出す
python3 scripts/parse_a29_conditions.py       # （参考）国土数値情報A29の自治体別利用条件
python3 scripts/build_db.py                   # → kminpaku_data/*.sqlite
python3 scripts/selftest.py http://127.0.0.1:8080   # 分かっている住所8件で当たりを確かめる
```

- 生データは `/mnt/data/kminpaku/raw/` に残します（取り直しません）。
- **用途地域の面は1mまで間引き、座標をint32に詰めています**（GeoJSONのままだと全国1.9GB、
  詰めて約57MB）。精度は約1cmです。
- **住所から都道府県名を切り出すときは、47の名前で照合します。** 最短一致で切ると
  「京都府京都市」が「京都」になり、京都府の全住所が未収録になります。

## 出典

- 用途地域: 国土交通省 都市局「都市計画決定GISデータ（全国）」令和7年度版
  https://www.mlit.go.jp/toshi/tosiko/toshi_tosiko_tk_000087.html
  掲載データは、建築確認申請や不動産重要事項説明等の手続に用いることを保証するものではなく、
  参考情報として利用を想定しています（出典サイトの記載）。
- 上乗せ条例の一覧: 一般財団法人 地方自治研究機構「民泊（住宅宿泊事業）に関する条例」
- 制限の中身: 観光庁「民泊の実施制限に関する地方公共団体の条例のとりまとめについて」

**国土数値情報の用途地域（A29）は使っていません。** 自治体ごとに利用条件が違い、
1,213自治体のうち201（16.6%）が有償利用不可・公開不可・回答なしで、そこに大阪市・京都市・
大田区・渋谷区・豊島区・八王子市・那覇市が入るためです（`scripts/parse_a29_conditions.py` で確認できます）。
