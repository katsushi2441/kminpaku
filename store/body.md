住所を入れると、**その場所の用途地域**と、**その自治体の民泊の上乗せ条例**を返すシステムです。

民泊には制度が3つあります。住宅宿泊事業法（届出・年180日）、国家戦略特別区域法の特区民泊（認定）、旅館業法の簡易宿所（許可）。窓口も条件も別々で、住所から横断して引ける場所がありません。

■ 返ってくるもの

1. **用途地域** … 名称・建蔽率・容積率。住居専用系の地域なら、条例の制限が置かれやすい区分だと添えます
2. **上乗せ条例** … その自治体の条例名・公布日・施行日と、区域・期間の制限を**条例に書いてある文のまま**
3. **3つの制度** … 手続き（届出／認定／許可）・日数の上限・区域の考え方の違い

■ 収録

- 用途地域 102,159面・1,215市区町村（全国47都道府県）
- 上乗せ条例 63自治体（令和8年4月1日時点の一覧）
- 制限の中身 58自治体（令和3年4月1日時点・観光庁のとりまとめ）

**用途地域は都道府県ごとに1ファイル**です。要る県だけ置けば動きます。置いていない県は「未収録」と返します。

■ しないこと

- **営業できる・できないを断定しません。** 調べる前の下ごしらえです
- **条例を要約・解釈しません。** 出すのは原文のまま
- **収録していない自治体を「区域外」と書きません。**「未収録」と書いて区別します
- **外部のAIやAPIに住所を送りません。** 住所の位置を引く国土地理院の検索だけ使います

最後の判断は自治体の窓口（保健所・都市計画課）で確かめる前提の作りです。

■ 置き方

1. kminpaku.php と kminpaku_data/ を置く
2. その階層の .htaccess に AddHandler php-script .php を書く
3. ブラウザで開く

PHP 8 と PDO SQLite だけで動きます。データベースサーバーも常駐プロセスもポートも要りません。判定は0.1秒前後です（全国データで実測）。

■ データを新しくする

同梱のPythonを動かせば、最新のデータで作り直せます。

```
python3 scripts/fetch_youto.py --all
python3 scripts/fetch_jorei.py
python3 scripts/parse_jorei_pdf.py
python3 scripts/build_db.py
python3 scripts/selftest.py http://…
```

分かっている住所8件で当たりを確かめる selftest.py が付いています。

■ 出典

- 用途地域: 国土交通省 都市局「都市計画決定GISデータ（全国）」令和7年度版
- 上乗せ条例の一覧: 一般財団法人 地方自治研究機構
- 制限の中身: 観光庁「民泊の実施制限に関する地方公共団体の条例のとりまとめについて」

出典サイトには「掲載データは、建築確認申請や不動産重要事項説明等の手続に用いることを保証するものではなく、参考情報として利用を想定しています」と明記されています。画面にもそのまま出しています。

なお、国土数値情報の用途地域（A29）は使っていません。自治体ごとに利用条件が違い、1,213自治体のうち201が有償利用不可・公開不可・回答なしで、そこに大阪市・京都市・大田区・渋谷区が入るためです。その確認スクリプトも同梱しています。

- 民泊の運営代行、不動産、行政書士の方
- 自分の物件がどの制度なら通るのか、先に当たりを付けたい方
