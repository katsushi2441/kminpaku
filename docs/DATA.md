# kminpaku が使うデータ（実測ずみ・2026-09-23）

## 1. 用途地域（住所→どの地域か）
- 国土数値情報 **A29 用途地域 第2.1版**（データ作成年度 2019年度／令和元年度）
  https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-A29-v2_1.html
- 属性: 行政区域コード・都道府県名・市区町村名・用途地域分類コード・用途地域名・建ぺい率・容積率
- **ライセンスに注意**: 第2.1版（令和元年度）は国土数値情報ダウンロードサイト利用規約（政府標準利用規約準拠）だが、
  「**各市区町村で定められた利用条件を必ず遵守**」と明記されている。第1.0版（平成23年度）は**非商用**なので使わない。
  → 出品前に、収録する市区町村の利用条件を確認して `data/a29_license.json` に記録する。

## 2. 民泊の上乗せ条例（区域・期間の制限）
- 国のとりまとめ: 観光庁「民泊の実施制限に関する地方公共団体の条例のとりまとめについて」（PDF 61ページ）
  https://www.mlit.go.jp/kankocho/minpaku/content/001418351.pdf
  **令和3年4月1日時点・58自治体。5年前の内容で、そのままでは使えない。**
- 最新の追跡: 一般財団法人 地方自治研究機構「民泊（住宅宿泊事業）に関する条例」
  https://www.rilg.or.jp/htdocs/img/reiki/071_minpaku.htm
  **令和8年4月1日時点で62自治体**。令和7年12月に墨田区・葛飾区、令和8年3月に江戸川区・高槻市が制定。
  表は4つ（特別区22／市21／都道府県19／その他1）。列は 自治体・条例名・公布日・施行日・類型番号。
- **条例の本文は各自治体の例規集にある。** 区域と期間は条例ごとに書き方が違うので、原文へのリンクを必ず残す。

## 3. 制度の枠組み（3つある。ここが一元化されていない＝国会でも指摘済み）
- 住宅宿泊事業法（民泊新法）… 届出。年間180日上限。条例で区域・期間をさらに制限できる（法18条）
- 国家戦略特別区域法（特区民泊）… 認定。区域が限られる（大阪市・東京都大田区ほか）
- 旅館業法（簡易宿所）… 許可。日数上限なし
- 小西洋之参議院議員の質問主意書「旅館業法における簡易宿所の課題に関する質問主意書」が、
  この3形態を一元的に管理・把握するシステムが機能不全になる懸念を指摘している（kshuisho 収録）。

## 用途地域は A29 を使わない（2026-09-23 に判明）

**国土数値情報 A29 第2.1版は、自治体ごとに利用条件が違う。** 1,213自治体のうち

| 条件 | 件数 |
|---|---|
| オープンデータ公開可 | 960 |
| 条件つき（有償利用不可・再配信不可など） | 176 |
| 公開不可 | 56 |
| 回答なし | 15 |
| 資料の提供なし | 6 |

有償の製品に入れられるのは **1,012（83.4%）** だけ。しかも入れられない側に
**大阪市（公開不可）・京都市・大田区・渋谷区・江東区・練馬区（有償利用不可）・
豊島区・八王子市・姫路市・那覇市（公開不可）** という、民泊で肝心な自治体が並ぶ。
→ `scripts/parse_a29_conditions.py` → `data/a29_conditions.json`

**代わりに使うもの: 国土交通省 都市局「都市計画決定GISデータ（全国）」令和7年度版**
https://www.mlit.go.jp/toshi/tosiko/toshi_tosiko_tk_000087.html

- 国土交通省の責任で全国分を整備し、無償で提供。自治体ごとの有償利用不可・再配信不可が無い
- 令和7年度版。A29（2019年度）より6年新しい
- 都道府県ごとの GeoJSON zip。中は市区町村ごとに1ファイル（`27_大阪府/27100_大阪市/27100_youto.geojson`）
  **政令市は区ごとに分かれず市で1本**（区名でファイルを探すと当たらない）
- 属性: YoutoName / YoutoCode / BCR（建蔽率）/ FAR（容積率）/ Pref / Cityname / Citycode
- **必ず画面に出す一文**（出典サイトの記載そのまま）:
  「掲載データは、建築確認申請や不動産重要事項説明等の手続に用いることを保証するものではなく、
  参考情報として利用を想定しています」
- 「地方公共団体がGISデータを保有していない等の理由で掲載されていないデータがある」
  → 載っていない自治体は「区域外」ではなく **「未収録」** と書く
